# UI/UX 피드백 가이드 (비개발자용)

> 로컬호스트에서 화면을 보면서 수정사항을 개발자에게 전달하는 방법

---

## 📸 기본 준비사항

### 1. 스크린샷 찍는 방법
```
Windows:
- Windows + Shift + S : 원하는 영역만 캡처
- Windows + PrtScn : 전체 화면 캡처

Mac:
- Command + Shift + 4 : 원하는 영역만 캡처
- Command + Shift + 3 : 전체 화면 캡처
```

### 2. 브라우저 정보 확인
- 주소창에 표시된 URL 복사하기
- 예: `http://localhost:5174/dashboard`

### 3. 어떤 브라우저를 사용하는지 확인
- Chrome, Edge, Safari 등

## 📝 수정사항 전달 템플릿

### 템플릿 1: 버그 발견 시

```
📍 발견 위치:
- 페이지: [예: 대시보드 / 안전교육 목록 / 마이페이지]
- 메뉴 경로: [예: 좌측 메뉴 > 안전보건교육 > 교육 목록]
- URL: http://localhost:5174/...

🔴 문제 설명:
[무엇이 잘못되었는지 간단히 설명]
예: "저장 버튼을 눌렀는데 아무 반응이 없어요"
예: "날짜가 이상하게 표시돼요 (2026-02-15 대신 NaN으로 표시)"

📋 재현 방법:
1. [첫 번째 단계] 예: 안전교육 페이지로 이동
2. [두 번째 단계] 예: 교육 등록 버튼 클릭
3. [세 번째 단계] 예: 제목만 입력하고 저장 버튼 클릭
4. [결과] 예: 에러 메시지 표시됨

✅ 기대했던 동작:
[원래 어떻게 작동해야 하는지]
예: "저장 완료 메시지가 뜨고 목록으로 돌아가야 해요"

📎 첨부:
[스크린샷 파일명 또는 이미지 첨부]
```

## 💬 실전 예시

### 예시 1: 버튼이 안 눌러질 때
```
📍 위치: 안전교육 목록 페이지
URL: http://localhost:5174/safety-education

🔴 문제: 교육 등록 버튼을 클릭했는데 아무 반응이 없어요

📋 재현 방법:
1. 좌측 메뉴에서 "안전보건교육" 클릭
2. "교육 목록" 클릭
3. 우측 상단의 파란색 "등록" 버튼 클릭
4. 아무 일도 안 일어남

✅ 기대: 교육 등록 페이지로 이동해야 함

📎 스크린샷: [버튼 위치 스크린샷 첨부]
```

### 예시 2: 날짜가 이상하게 표시될 때
```
📍 위치: 안전교육 상세 페이지
URL: http://localhost:5174/safety-education/detail/123

🔴 문제: 교육 시작일이 "NaN-NaN-NaN"으로 표시돼요

📋 재현 방법:
1. 안전교육 목록에서 아무 교육이나 클릭
2. 상세 페이지로 이동
3. 교육 정보 섹션의 "교육 시작일" 확인
4. "NaN-NaN-NaN" 으로 잘못 표시됨

✅ 기대: "2026-02-15" 처럼 정상적인 날짜 표시

📎 스크린샷: [날짜 표시 부분 스크린샷]
```

### 예시 3: 디자인 수정 요청
```
📍 위치: 대시보드
URL: http://localhost:5174/dashboard

🎨 현재 상태: 날씨 위젯의 텍스트가 너무 작아서 읽기 어려워요

💡 변경 요청:
- 날씨 위젯의 온도 숫자를 더 크게
- 날씨 설명 텍스트도 조금 더 키워주세요

📎 스크린샷: [현재 날씨 위젯 스크린샷]
```

### 예시 4: 테이블 데이터 문제
```
📍 위치: 공지사항 목록
URL: http://localhost:5174/notice

🔴 문제:
- 작성자 이름이 안 나와요 (빈칸으로 표시)
- 조회수도 표시 안 돼요

📋 재현 방법:
1. 좌측 메뉴에서 "공지사항" 클릭
2. 공지사항 목록 테이블 확인
3. "작성자" 열이 비어있음
4. "조회수" 열도 비어있음

✅ 기대: 작성자 이름과 조회수가 표시되어야 함

📎 스크린샷: [테이블 스크린샷]
```

## 🎯 효과적으로 전달하는 팁

### ✅ 좋은 피드백
- "안전교육 목록 페이지에서 등록 버튼을 눌렀는데 반응이 없어요" (구체적)
- "대시보드 날씨 위젯에서 온도가 '25°C'가 아니라 'NaN°C'로 나와요" (정확한 값 포함)
- "공지사항 테이블에서 작성자 열이 비어있어요" (정확한 위치)

### ❌ 피해야 할 피드백
- "안 돼요" (무엇이 안 되는지 불명확)
- "이상해요" (무엇이 이상한지 불명확)
- "거기" "그거" (어디인지 불명확)

### 📌 꼭 포함해야 할 정보
1. **어디서**: 페이지 이름, 메뉴 경로
2. **무엇이**: 버튼, 텍스트, 이미지 등 구체적 요소
3. **어떻게**: 재현 단계
4. **기대**: 원래 어떻게 되어야 하는지
5. **스크린샷**: 시각적 증거

## 🔧 개발자 도구 활용 (선택사항)

브라우저에서 `F12` 키를 누르면 개발자 도구가 열립니다.
개발자에게 추가 정보를 제공할 때 유용합니다.

### 콘솔 에러 확인
```
1. F12 누르기
2. "Console" 탭 클릭
3. 빨간색 에러 메시지가 있다면 스크린샷
4. 개발자에게 전달: "콘솔에 이런 에러가 떴어요"
```

### 네트워크 에러 확인
```
1. F12 누르기
2. "Network" 탭 클릭
3. 페이지에서 동작 수행 (버튼 클릭 등)
4. 빨간색으로 표시된 항목이 있다면 스크린샷
5. 개발자에게 전달: "네트워크 탭에서 이런 에러가 보여요"
```
