# TODO 주석 작성 가이드

## 표준 형식

```typescript
/**
 * TODO: [우선순위] 작업 설명
 * - 담당: 팀명/담당자
 * - 예상 완료: YYYY-MM-DD
 * - 의존성: 백엔드 API / 디자인 / 기획 확정
 * - 임시 처리: 현재 어떻게 처리하고 있는지
 * - 관련 이슈: #123
 */
```

## 우선순위

- `[P0]` - 긴급 (즉시 처리 필요, 서비스 영향)
- `[P1]` - 높음 (주요 기능, 빠른 처리 필요)
- `[P2]` - 중간 (개선 사항, 일정 내 처리)
- `[P3]` - 낮음 (부가 기능, 여유 시 처리)

## 작성 규칙

1. **명확한 설명**: 무엇을 해야 하는지 구체적으로 작성
2. **담당자 명시**: 누가 처리해야 하는지 명확히
3. **예상 일정**: 현실적인 완료 예상일 작성
4. **의존성 표시**: 다른 작업에 의존하는 경우 명시
5. **임시 처리 방법**: 현재 어떻게 우회하고 있는지 기록

## 완료 후 처리

TODO가 완료되면:
1. TODO 주석 제거
2. 코드 정리
3. 관련 문서 업데이트
4. Git commit 메시지에 TODO 해결 명시

```bash
git commit -m "fix: 공지사항 작성자 필드 추가 (TODO #123 해결)"
```
